# Frontend

The frontend is a Vite, React, and TypeScript application for the Rails API.

## Commands

Run these from this directory:

```sh
npm ci
npm run dev
npm run check
```

`npm run check` runs ESLint, TypeScript validation, and a production build. The API is
expected at `http://localhost:3004/api/v1` while developing locally.

See the repository [README](../README.md) for the complete application setup.
